# Faculty Finance Flow

Faculty Finance Flow is a salary planning workspace for modeling faculty compensation under the UGC 7th CPC framework. It helps teams compare candidate scenarios, inspect pay matrix progression, estimate arrears, and run cleaner salary planning workflows across desktop and mobile.

## What it does

- Salary calculator for faculty levels and pay cells
- Multi-candidate comparison across projected growth paths
- Pay matrix exploration with designation-level detail
- Arrears estimation and scenario planning
- Configurable salary inputs for DA, HRA, pension mode, increments, and edge cases

## Local development

```bash
npm install
npm run dev
```

## Build and test

```bash
npm run build
npm run test
```
